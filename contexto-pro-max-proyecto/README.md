# contexto-pro-max-proyecto (Claude Code local)

Memoria detallada + MAPA (índice, sub-índice y grafo) para **cualquier carpeta de trabajo**. El MAPA enruta la lectura por **título de sección**: Claude ubica el tema y salta al sub-bloque, sin leer la memoria completa.

- **Corre solo en Claude Code, en local.**
- **Se parametriza** con `contexto-pro-max.config.md` en la raíz de la carpeta (ver `references/config.md`).
- **Deja el arranque en `CLAUDE.md`** (bloque de `references/claude-md.md`), en vez de pegar instrucciones en un proyecto de Cowork.
- **Respaldo en GitHub opcional** (repo privado, PAT de mínimo privilegio).

Uso: «monta la memoria y el MAPA de esta carpeta» o «actualízalos». Licencia MIT.
